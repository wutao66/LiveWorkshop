01 / CONVERT

一种回忆，
六种打开方式。

从相册里的一张照片，到生活中的一段视频。
选择素材，调整设置，让灵感自然发生。

视频 → Live

把精彩片段，变成可长按播放的实况照片。

Live → 视频

将实况照片转换为视频，让播放与分享更方便。

GIF → Live

把喜欢的动图，制作成相册里的动态瞬间。

Live → GIF

将实况照片导出为 GIF，用动图表达心情。

多图 → Live

把多张图片串成一段动态回忆。

多图 → GIF

按顺序播放照片，制作属于你的 GIF。

02 / CREATE

方圆之间，
拼出你的主角。

从画面构图到动态宫格，
让每一个细节，都更像你。

自由构图

把注意力，留给主角。

缩放、拖动画面，调整圆角和片段起点。选择时长、循环与输出质量，慢慢找到喜欢的效果。

Live 宫格

把喜欢的瞬间，放在一起。

组合多张 Live Photo，使用预设宫格或自由布局，把不同角度的回忆拼成一张动态作品。

适用范围与联系渠道

本隐私协议适用于 Live 工坊（Live Workshop）App 及本官网。开发者的隐私联系邮箱为 wt1377126991@163.com。本文说明数据如何被处理，以及您可以作出的选择。

1. 您的素材如何处理

转换与 Live 宫格功能在设备上读取和处理您主动选择的照片、视频及音频，用于预览、编辑、合成、导出和保存。核心媒体处理不会将这些素材上传至开发者服务器。若原始素材仅存于 iCloud，Apple 系统可能联网下载，相关处理适用 Apple 的隐私政策。

2. 权限及其用途

相册读取权限：用于选择和读取待处理素材；相册写入权限：用于保存生成的作品。使用拍摄功能时，相机权限用于拍摄，麦克风权限用于录音，位置权限用于拍摄位置记录。相关权限由系统询问，您可以拒绝，或在 iOS 设置中随时调整。拒绝某项权限仅影响依赖该权限的功能。位置记录可能成为素材元数据的一部分，请在分享前留意。

3. 本地保存、临时文件与删除

语言偏好及会员权益状态保存在设备上。媒体处理会生成本地临时文件，部分文件可能保留至系统清理或卸载 App。相册或其他导出位置中的作品由您自行管理，卸载 App 不会删除这些作品。若开启 iCloud 照片，作品可能按您的系统设置同步。Apple 管理购买记录；设备钥匙串中的会员状态可能在卸载后保留。

4. 会员购买及第三方服务

会员商品查询、购买、恢复购买及交易验证通过 Apple App Store 处理，可能需要联网。我们不读取您的银行卡信息。主动将作品分享或导出至其他应用后，接收服务可能存储或上传作品，其数据处理适用该服务的隐私政策。请在分享前确认作品及元数据是否包含私人信息。

5. 联系我们时提供的信息

您发送反馈邮件时，我们会收到您主动提供的邮箱、邮件内容及附件，仅用于处理反馈、支持或隐私请求。邮件传输和保存还涉及您使用的邮件服务商及联系邮箱的邮件服务商。请勿发送密码、支付信息或无关私人素材。我们仅在处理请求所需期间保留反馈信息；依法需要保留的除外。

6. 官网访问及托管

本官网为静态网站，不设置登录或反馈表单，不主动使用 Cookie、广告追踪器或统计脚本。网站托管平台 GitHub Pages 可能处理 IP 地址、请求时间和浏览器等技术信息，以提供服务和维护安全；其处理方式适用 GitHub 隐私声明。点击邮件链接会打开您设备上的邮件应用；点击复制邮箱时，仅把公开联系邮箱写入剪贴板，不读取剪贴板中已有内容。

7. 您的选择与权利

您可以调整系统权限、删除自己保存的作品，或卸载 App 删除其沙盒数据。关于您通过邮件提供的反馈信息，可联系我们申请查询、更正或删除；依法需要保留的信息除外。处理请求时，我们可能需要合理核实您的身份，但请不要主动提供无关的敏感证件信息。

8. 未成年人及信息安全

未成年人请在监护人指导下使用涉及素材授权、付费或个人信息的功能。不要未经同意分享他人的照片、声音或私人信息。请妥善保护设备、Apple 账户及邮件账户，并保留重要原始素材。我们不保证任何存储或传输方式绝对安全。

9. 协议更新

本协议可能随功能和数据处理方式变化而更新，更新内容及日期会展示在此页面。若发生对个人信息处理具有重大影响的变化，我们将按适用要求提供通知或取得必要同意。

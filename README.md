# Live 工坊 · Live Workshop 官网

适配手机、平板和桌面的静态官网，无需安装依赖或编译。

- `index.html`：产品介绍
- `privacy.html`：隐私协议
- `terms.html`：使用条款
- `support.html`：常见问题与联系邮箱

所有图片、样式和交互均为本地资源，无广告追踪或统计脚本。

## GitHub Pages

将此目录作为独立仓库上传，默认分支使用 `main`。在仓库 Settings → Pages 中将 Source 设置为 GitHub Actions。推送后，工作流会自动发布网站。

本网站不包含 iOS 项目源代码。上架后可在首页补充真实 App Store 下载链接；隐私协议和支持页面可直接填写至 App Store Connect。
